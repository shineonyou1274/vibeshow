1-5개인 인텔리전스 켜기

10분 · 기본 세팅

제미나이가 대화창에서 답만 하는 데서 끝나지 않고, 내 구글 문서·시트·캘린더에 직접 결과를 만들어 넣으려면 개인 인텔리전스와 연결된 앱을 켜야 합니다. 오늘 세팅의 마지막 단계입니다.

  1. 제미나이 화면 왼쪽 아래의 설정을 누르고 개인 인텔리전스(Personal Intelligence)를 엽니다.
  2. 화면 맨 위의 개인 인텔리전스 스위치가 꺼져 있으면 켭니다.
  3. 설정 메뉴의 활동(Activity)에서 활동 기록이 '사용 중지'로 되어 있으면 '사용 설정'으로 바꿉니다. 활동 기록이 꺼져 있으면 앱을 연결할 수 없습니다.
  4. 개인 인텔리전스 화면으로 돌아와 연결된 앱(Connected Apps)으로 들어갑니다.
  5. Google Workspace가 '사용 중' 목록에 없으면 전체 목록에서 찾아 추가를 누릅니다.
  6. 연결 안내 화면에 나오는 동의란에 체크한 뒤 연결합니다.

    발전된 프롬프트환경 교육 + 생명 + 분리수거 미니게임
    HTML5 Canvas와 JavaScript를 사용해서 '공룡 게임 스타일의 횡스크롤 러닝 게임'을 단일 HTML 파일로 만들어줘. 이 게임은 [초등학생]들을 위한 환경 교육과 게임 프로그래밍 개념 학습을 통합하는 교육용 게임이야.

게임 메커닉: 플레이어는 빨간 사각형(캐릭터)이고, 화면 오른쪽에서 초록색 직사각형(장애물)이 무작위 속도로 계속 다가와. 스페이스바나 마우스 클릭을 누르면 캐릭터가 점프하고, 현실적인 중력을 받아 다시 바닥으로 내려와야 해. 장애물과 닿으면 생명이 1개 감소해.

생명 시스템: 플레이어는 총 3개의 하트(생명)를 가지고 시작해. 각 충돌마다 하트가 1개씩 감소하고, 모든 하트가 없어지면 게임 오버돼.

점수 시스템: 버틴 시간(초 단위)만큼 점수가 올라가. 점수는 화면 상단에 실시간으로 표시돼.

교육적 통합 - 환경 보호 미션: 게임 진행 중에 노란색 작은 원형 객체(쓰레기)가 무작위로 나타나. 플레이어가 캐릭터로 쓰레기에 닿으면 수집돼. 수집한 쓰레기 개수를 화면에 표시해. 게임 오버 후 또는 특정 점수 도달 시 '분리수거 미니게임' 화면으로 전환돼. 이 화면에서 플레이어는 수집한 쓰레기를 플라스틱, 종이, 금속 등 올바른 분류로 드래그해서 분류하는 간단한 상호작용을 완료해야 해. 분류를 완료하면 최종 점수와 함께 환경 보호 메시지를 표시해.

기술 요구사항: 모든 코드는 단일 HTML 파일에 포함되어야 하고, 외부 라이브러리 없이 순수 HTML5 Canvas와 JavaScript만 사용해. 게임 루프는 requestAnimationFrame을 사용해서 부드러운 60fps 성능을 유지해. 충돌 감지는 간단한 사각형 교집합 알고리즘(AABB)을 사용해. 반응형 디자인으로 다양한 화면 크기에 적응하게 해.

사용자 경험: 시작 화면에서 '게임 시작' 버튼을 포함해. 게임 오버 후 '다시 시작' 옵션을 제공해. 조작법(스페이스바/마우스 클릭으로 점프)을 화면에 명확히 표시해. 게임의 환경 교육 목적을 설명하는 간단한 인트로 텍스트를 포함해.

코드 구조: 게임 객체(플레이어, 장애물, 쓰레기)를 클래스 또는 객체로 구현해서 유지보수성을 높여. 상태 관리(시작, 진행 중, 게임 오버, 분류 미션)를 명확히 해. 모든 매직 넘버는 상수로 정의해서 난이도 조정이 쉽도록 해.
    

    



    
  
    3-9🚀 슈팅 게임과 💩 피하기 게임의 교육적 변신
    
  
    12분 · 게임 만들기
    
  
    슈팅 게임 — "스트레스 타파!"
    
  
    인기 예시: 갤러그, 인베이더, 벽돌깨기 스타일 변형. "틀린 답을 쏘아 맞히기"처럼 바꾸면 교과 퀴즈가 됩니다.
    
  
    
    
    발사체 배열(Projectiles) — 날아가는 미사일을 실시간으로 그리고, 화면 밖으로 나가면 삭제하는 시스템
    
    
    키 입력 제어(Key Input Control) — 왼쪽/오른쪽 화살표 키로 우주선을 빠르고 부드럽게 움직이는 제어
    
    
    적 캐릭터 생성(Enemy Spawning) — 화면 위에서 일정 시간마다 적 우주선이 내려오는 규칙
    
  
    
  
    마법의 프롬프트클래식 슈팅
    HTML5 Canvas를 사용해서 화면 아래쪽에서 우주선이 미사일을 쏘아 위에서 내려오는 적을 맞추는 '클래식 슈팅 게임'을 만들어줘. 좌우 화살표 키로 움직이고, 스페이스바를 누르면 미사일이 발사되어야 해. 적들은 화면 위쪽에서 일정 간격으로 생성되어 아래로 내려오고, 적을 맞추면 점수가 올라가. 적이 화면 맨 아래에 닿거나 내 우주선과 충돌하면 게임 오버가 되게 해줘. 레트로 아케이드 느낌의 세련된 다크 테마 디자인으로 CSS를 구성해줘.
    

  
    "똥피하기"의 이해
    
  
    Q1. 똥피하기와 러닝 게임은 비슷한가요? 네, 핵심 원리는 똑같습니다. 두 게임 모두 충돌 판정이라는 물리 코딩의 가장 기초적이고 중요한 개념을 익히는 게임이에요. 다른 것은 화면의 방향(축)뿐입니다.
    
  
    
    
    💧☁️🌱
    피하기 (하강형) — Y축 중심
    하늘에서 장애물이 떨어지고, 플레이어는 바닥에서 좌우로만 움직여 피합니다.
    
    
    🌵🦖
    러닝 (횡스크롤) — X축 중심
    장애물이 오른쪽에서 왼쪽으로 다가오고, 플레이어는 제자리에서 점프해 피합니다.
    
  
    
  

  
    Q2. "똥"은 학교에서 좀… 교육적으로 어떻게 풀 수 있을까요? 떨어지는 장애물과 플레이어 캐릭터의 '스킨(디자인)'과 '스토리'만 바꾸면 훌륭한 과목 연계 게임이 됩니다. 학생들이 직접 기획하게 해 보세요.
    
  
    
    
    🌧️
    [환경/과학] 산성비 피하기
    피할 것: 산성비(파란 물방울), 매연 구름(회색) → 하트 감소
    먹을 것: 햇살(노란 원), 친환경 에너지(바람개비) → 점수·회복
    메시지: "지구를 구했습니다! 일상에서 탄소를 줄이는 방법은?"
    
    
    🏗️
    [안전 교육] 지진 대피 훈련
    피할 것: 떨어지는 벽돌, 깨진 유리창 → 게임 오버
    먹을 것: 안전모, 손전등, 소화기 → 점수 상승·무적 상태
    
    
    📖
    [국어/외국어] 올바른 맞춤법 받기
    피할 것: 잘못된 맞춤법('어의없다', '않하고') → 감점
    먹을 것: 올바른 맞춤법('어처구니없다', '안 하고') → 득점
    
  
    
  
    마법의 프롬프트산성비 피하기 · 복사해서 바로 쓰기
    HTML5 Canvas와 JavaScript를 사용해서 '산성비 피하기 게임'을 단일 HTML 파일로 제작해줘. 이 게임은 [초등학생] 환경 안전 교육용 게임이야.
1. 게임 디자인:
   - 배경은 연한 회색 하늘(매연 느낌)로 해줘.
   - 플레이어는 화면 맨 아래에서 움직이는 '초록색 새싹(가로 40px, 세로 40px)'이야. 좌우 방향키나 화면 터치로 움직여.
   - 하늘에서 떨어지는 장애물은 파란색 '산성비 물방울'과 회색 '매연 구름'이야. 무작위 위치에서 다른 속도로 떨어져야 해.
2. 아이템 시스템:
   - 가끔 하늘에서 노란색 '햇살(동그라미)' 아이템이 떨어져. 플레이어가 이걸 먹으면 점수가 10점 올라가.
3. 생명 및 게임 오버:
   - 플레이어는 하트 3개로 시작해. 산성비나 매연에 닿으면 하트가 1개씩 줄어들고, 0이 되면 게임 오버야.
   - 게임이 끝나면 '지구를 더 푸르게 만들어주세요!'라는 환경 메시지와 함께 '다시 하기' 버튼이 나타나게 해줘.
4. 기술 사양: 순수 자바스크립트와 Canvas만 사용하고 CSS로 모바일/PC 모두에서 플레이 가능하도록 반응형 레이아웃으로 작성해줘.
    

    



    
  
    3-10🧠 로직 게임 — "규칙과 생각의 힘"
    
  
    12분 · 게임 만들기
    
  
    로직 게임의 핵심은 If/Then, 곧 "만약 ~이면 → ~한다"는 규칙입니다. 프롬프트에 규칙을 If/Then 문장으로 적어 주면 AI가 훨씬 정확하게 만듭니다.
    

  
    1) "기억의 신전" — 사이먼 색상 패턴 기억 게임
    
  
    스토리: 비밀 신전의 문을 열기 위해 컴퓨터가 보여 주는 불빛 순서를 기억했다가 그대로 따라 누릅니다.
    
  
    
    
    만약(If) 플레이어가 누른 순서가 컴퓨터가 보여 준 패턴과 일치하면 → 점수가 올라가고 다음 단계(패턴이 1칸 더 길어짐)로
    
    
    만약(If) 입력 도중 하나라도 틀리면 → 게임 오버, 처음부터 다시
    
  
    
  
    
    
    🔔 미니 사이먼단계 0
    
    
    
      
      
    
    
    
    시작을 누르면 불빛 순서를 보여 줍니다. 그대로 따라 누르세요.
    
  
    
  
    마법의 프롬프트사이먼
    HTML5 Canvas와 CSS를 사용해서 '사이먼 패턴 기억 게임'을 단일 HTML 파일로 만들어줘.
1. 화면에는 빨강, 파랑, 초록, 노랑 4개의 큰 버튼이 사각형 격자 모양으로 배치되어 있어.
2. 게임이 시작되면 컴퓨터가 무작위로 버튼을 하나씩 밝게 반짝이며 0.5초 간격으로 보여줘 (예: 빨강 -> 초록 -> 빨강).
3. 플레이어는 컴퓨터가 보여준 순서대로 버튼을 클릭해야 해. 클릭할 때마다 해당 버튼이 반짝이고 소리가 나게 해줘.
4. 모든 패턴을 맞추면 '성공!' 메시지와 함께 패턴이 1단계 더 늘어나서 난이도가 올라가고, 도중에 순서가 틀리면 즉시 경고음과 함께 게임 오버 화면이 뜨고 최종 달성 스테이지를 표시해줘.
    
  

  
    2) "깨끗한 바다 만들기" — 소코반 스타일 밀기 퍼즐
    
  
    스토리: 잠수부가 되어 바다 밑에 흩어진 플라스틱 쓰레기(상자)를 밀어서 '쓰레기 수거함(목표 지점)'에 모두 넣는 정돈 게임입니다.
    
  
    
    
    만약(If) 쓰레기 상자를 벽이나 다른 상자 쪽으로 밀려고 하면 → 더 이상 밀리지 않고 멈춥니다 (밀기 규칙)
    
    
    만약(If) 모든 쓰레기 상자가 수거함 격자 위에 겹치면 → 스테이지 클리어
    
  
    
  
    마법의 프롬프트소코반
    HTML5 Canvas를 활용해서 2D 타일 맵 기반의 '소코반(Sokoban) 스타일 바다 정화 게임'을 단일 HTML 파일로 제작해줘.
1. 8x8 격자(그리드)로 맵을 구성하고, 지나갈 수 없는 '산호초 바위(벽)', 플레이어 '잠수부', 밀어야 하는 '플라스틱 상자 3개', 상자를 넣어야 하는 '분리수거 버킷 3개'를 배치해줘.
2. 키보드 방향키로 잠수부를 움직여서 플라스틱 상자를 밀어 이동시킬 수 있어야 해. 단, 잠수부는 상자를 당길 수는 없고 '밀기'만 가능하며, 상자 2개를 동시에 밀거나 벽 너머로 밀 수는 없어.
3. 모든 플라스틱 상자가 버킷 위치에 도달하면 화면 중앙에 '바다 청소 완료!' 메시지와 함께 축하 효과(폭죽 애니메이션 등)가 나타나게 해줘.
4. 바닷속 분위기가 나는 예쁜 파란색 톤의 디자인으로 구성해줘.

function getSheet_() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName(SHEET_NAME);
  if (!sheet) {
    sheet = ss.insertSheet(SHEET_NAME);
  }
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(HEADERS);
    sheet.setFrozenRows(1);
  }
  return sheet;
}

// 화면에서 보낸 내용을 시트에 한 줄 쌓습니다.
function submitFeedback(data) {
  const cls = String(data && data.cls || '').trim();
  const level = Number(data && data.level);
  const line = String(data && data.line || '').trim();
  if (!line) throw new Error('오늘의 한 줄을 적어 주세요.');
  if (!(level >= 1 && level <= 5)) throw new Error('이해도를 골라 주세요.');

  // 여러 명이 동시에 보내도 줄이 겹치지 않게 잠급니다.
  const lock = LockService.getScriptLock();
  lock.waitLock(10000);
  try {
    getSheet_().appendRow([new Date(), cls, level, line.slice(0, 300)]);
  } finally {
    lock.releaseLock();
  }
  return '제출됐습니다';
}

다음 6가지 항목을 순차적으로 다루세요. 사용자가 답변을 어려워하면 전문가로서 2~3개의 구체적인 객관식 선택지를 제안하세요.
a) 배경 및 목표: 왜 이 도구가 필요한지, 어떤 문제를 해결하고자 하는지 확인.
b) 사용자 페르소나: 주요 사용자(교사, 학생, 학부모 등)와 사용 상황 확인.
c) 핵심 기능 (Feature List): 필수 기능(Must-have)과 권장 기능(Nice-to-have)을 구분하여 구체화.
d) 데이터 구조 (Spreadsheet Design): DB로 활용할 구글 시트의 시트 이름과 열(Column) 구조를 제안하고 확인.
e) UI/UX 컨셉: 화면 구성 및 디자인 스타일 확인. (제안 예시: Tailwind CSS를 활용한 모바일 친화적 구성, 파스텔톤의 귀엽고 부드러운 UI, 대구동성로체 등 감성적인 웹폰트 적용 등)

- **필수 포함 제약 조건(Constraints):** 최종 PRD 안에는 다음 3가지 개발 원칙이 반드시 포함되어야 합니다.
  1) Code must be separated into `Code.gs` and `index.html`.
  2) The code must include functions to automatically create the required Spreadsheet and headers upon initial execution.
  3) The AI coder must provide clear instructions on how to test the execution button and how to deploy the web app as a final step.
- **PRD 구조 템플릿:** [Context & Goals] -> [Target Persona] -> [Core Features] -> [Spreadsheet Database Schema] -> [UI/UX Specs] -> [User Flow] -> [Strict Constraints & Deployment]
