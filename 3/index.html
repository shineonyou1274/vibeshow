3-1말은 짧게, 대화는 계속

15분 · 강사 시범

처음부터 잘 설명하지 않아도 됩니다. 떠오르는 말 한마디로 시작하고, 나온 화면을 보면서 다시 말해 보세요. AI가 엉뚱하게 이해하면 “아니, 그게 아니라…” 하고 고치면 됩니다.

강사가 직접 보여 줍니다

  1. “그림판 하나 만들어줘.”
  2. 화면을 보고 “너무 심심한데? 색연필 느낌으로 해줘.”
  3. 써 보다가 “아, 지우개가 없네. 넣어줘.”
  4. “그림도 저장할 수 있게 해줘.”
AI가 모르면 설명을 더하면 됩니다

“아까 내가 말한 건 배경이 아니라 버튼이야.” 화면을 캡처해 표시하거나, 잘 안 되는 장면을 구체적으로 말해도 좋아요. 결과는 직접 눌러 보고 확인합니다.

3-2사이트라는 집 만들기

20분 · 구글 사이트 기초

오늘 만든 도구를 하나씩 모을 집부터 만듭니다. 이름과 제목을 정하고, 빈 하위 페이지를 준비해요.

  1. 구글 사이트 새로 만들기를 열고 로그인합니다. 왼쪽 위에 사이트 이름을, 표지의 큰 글자에 페이지 제목을 씁니다.
  2. 오른쪽 삽입 → 이미지에서 이미지를 올리거나 선택합니다. 본인 사진이나 학생 정보 대신 공유 가능한 이미지를 씁니다.
  3. 페이지 → ＋ → 새 페이지로 감정 체크, 그림판, 게임방 페이지를 만듭니다. 페이지를 다른 페이지 아래로 끌어 하위 페이지로 정리할 수 있습니다.
  4. 메인 화면에서 삽입 → 버튼을 누르고 이름을 쓴 뒤 내 사이트의 페이지를 선택해 연결합니다.
  5. 위쪽 미리보기로 PC와 휴대전화 화면을 살펴보고, 게시에서 주소와 공개 범위를 확인합니다. 수정한 내용은 다시 게시해야 반영됩니다.
사이트 이름과 페이지 제목은 달라요

사이트 이름은 사이트의 이름표, 페이지 제목은 지금 보고 있는 화면의 제목입니다. 나중에 바꿔도 됩니다.

3-3HTML 통째로 넣어 보기

구글 사이트 기초 이어서

AI가 만든 코드는 사이트 안에 넣을 수 있습니다. 먼저 아래 작은 예제로 순서만 익히고, 이어서 내 도구를 넣어 봅니다.

  1. 아래 예제 코드 복사를 누릅니다.
  2. 구글 사이트에서 원하는 페이지를 열고 오른쪽 삽입 → 삽입 → 코드 삽입을 선택합니다.
  3. 복사한 코드를 통째로 붙여 넣고 다음 → 삽입을 누릅니다. CSS는 <style> 안, JavaScript는 <script> 안에 있어야 합니다.
  4. 들어간 상자의 모서리를 끌어 충분히 크게 만든 뒤, 미리보기에서 버튼을 눌러 봅니다. 게시한 주소에서도 다시 눌러 봅니다.
삽입 연습용 예제 코드
안 되면 순서대로 확인
코드 블록의 설명이나 백틱 없이 코드만 복사했나요? 상자의 높이가 충분한가요? 미리보기뿐 아니라 게시한 화면에서도 실행해 보세요. 복잡한 코드나 외부 리소스는 환경에 따라 제한될 수 있습니다.

3-4첫 도구: 오늘의 감정 체크
20분 · 첫마디 → 수정 → 삽입
“오늘 기분을 고를 수 있는 거 만들어줘.” 이 한 문장으로 시작합니다.
첫마디
오늘 기분을 고를 수 있는 거 만들어줘. 구글 사이트에 코드 삽입으로 넣어 쓸 수 있도록 HTML, CSS, JavaScript를 하나로 주고 외부 라이브러리 없이 만들어줘.
화면을 본 다음, 내 말로 한마디
모양 바꾸기
“표정을 더 귀엽게 해줘.”
기능 더하기
“고르면 짧은 응원 문장이 나왔으면 좋겠어.”
화면 맞추기
“휴대폰에서도 버튼이 크게 보여야 해.”
  1. 만든 화면에서 기분을 직접 눌러 보세요.
  2. “최종 코드를 처음부터 끝까지 하나로 다시 줘”라고 말합니다.
  3. 코드를 복사해 사이트의 감정 체크 페이지에 삽입하고 게시 화면에서 눌러 봅니다.
학생 정보는 넣지 않기
이름이나 실제 상담 내용은 AI에 입력하지 않습니다. 감정 기록 저장이 필요하면 어디에 남는지 먼저 확인하세요.


3-5두 번째 도구: 내 그림판
20분 · 써 보고 필요한 걸 말하기
“아이들이 그림 그릴 수 있는 그림판 만들어줘.” 잘 설명하려고 고민하지 말고 시작해요.
첫마디
아이들이 그림 그릴 수 있는 그림판 만들어줘. 구글 사이트에 삽입할 수 있는 단일 HTML 코드로 주고, 외부 라이브러리 없이 만들어줘.
그림을 직접 그리다가 말하기
  • “지우개가 없네. 넣어줘.”
  • “색깔을 좀 더 귀엽게 바꿔줘.”
  • “휴대폰에서도 손가락으로 그려지게 해줘.”
  • “그린 그림을 저장할 수 있게 해줘.”
마지막 전체 코드를 복사해 그림판 페이지에 넣고, 펜·지우개·저장이 실제로 되는지 확인합니다. 다운로드나 터치는 삽입 환경에 따라 제한될 수 있어요. 안 되면 오류를 AI에게 보여 주세요.


3-6잠깐 쉬어 가요
10분 · 쉬는 시간
사이트를 열어 지금까지 채운 도구를 둘러보세요. 아직 안 되는 게 있어도 괜찮아요. 돌아와서 그 화면을 AI에게 보여주면 됩니다.

“이 화면이 나왔는데 버튼이 안 눌려. 구글 사이트에 넣었어. 어디부터 확인하면 돼?”


3-7세 번째 도구: 교과 메모리 카드
15분 · 각자의 과목으로
같은 첫마디로 시작해도, 다음 대화가 다르면 게임도 달라집니다.
첫마디
우리 반에서 쓸 카드 짝맞추기 게임 만들어줘. 구글 사이트에 넣을 수 있는 단일 HTML 코드로 주고, 외부 라이브러리 없이 만들어줘.
영어
“단어랑 뜻을 맞추게 해줘.”
역사
“인물과 업적을 짝으로 해줘.”
수업 방식
“틀려도 점수 깎지 말고 다시 해 보라고 해줘.”
교과 내용과 정답을 선생님이 직접 검토하고 게임방에 삽입합니다. AI가 만든 예시가 사실과 다를 수 있습니다.


3-8네 번째 도구: 행성 탐험
15분 · 3D에 도전
“태양계 행성을 돌려 볼 수 있게 만들어줘.” 먼저 열어 보고, 원하는 걸 한마디씩 더해요.
첫마디
태양계 행성을 돌려 볼 수 있게 만들어줘. 행성을 누르면 이름이 나오고, 구글 사이트에 삽입할 수 있는 HTML 코드로 줘. 외부 라이브러리 없이 구현할 수 없다면 먼저 알려줘.
  • “행성 이름을 한글로 보여줘.”
  • “공전 속도를 조절할 수 있으면 좋겠어.”
  • “모바일에서도 손가락으로 조작하게 해줘.”
3D가 어렵다면 2D도 성공
AI가 만든 3D나 외부 라이브러리는 구글 사이트 삽입 환경에서 작동하지 않을 수 있어요. “외부 라이브러리 없이 돌아가는 2D 버전으로 바꿔줘”라고 이어서 말하고, 게시된 사이트에서 테스트합니다.
대안 요청
구글 사이트에 넣었더니 3D 화면이 안 나와. 외부 라이브러리 없이 HTML, CSS, JavaScript 하나로 동작하는 2D 태양계로 바꿔줘. 행성을 누르면 이름을 보여줘.


3-9내 사이트 살펴보기
5분 · 나누기
완성된 사이트를 서로 열어 보고, 결과물 하나를 골라 이렇게 물어봅니다.
“이건 처음에 뭐라고 말해서 만들었어요?”
처음부터 정답을 말한 게 아니라, 대화를 이어 가면서 내가 원하는 것을 발견했는지 이야기해 봅니다.
  1. 메인 버튼이 원하는 페이지로 이동하는지 확인합니다.
  2. 게시된 주소에서 감정 체크, 그림판, 게임을 눌러 봅니다.
  3. 내 사이트에 넣은 내용과 이미지에 학생 개인정보가 없는지 확인합니다.
